# 모니터링 일정 선택 — 오산대학교 2026-2

**동아리 모니터링 방문 일정 예약 웹사이트의 전체 소스코드**입니다.

- 총 **88개 동아리**: 전공 43, 취업 19, 창업 16, 일반 10
- **독립 예약 그룹 2개**: 전공·취업·일반 72개 통합 / 창업 16개 별도
- **2026.10.26.~11.27.**, 09:00~17:45 예약 시작, **15분 간격**, 점심 12:00~13:00 제외
- 기존 참고 사이트와 유사한 **월간 달력 + 주간 보기**, 예약 내역 색상 표시
- 동아리별 활성 예약 1건, 동일 예약 그룹·일시 중복 예약 금지
- 담당자 **사번 하나로 인증** 후 자신의 예약 그룹만 변경·취소·시간 차단
- 운영용 서버: **Supabase PostgreSQL + Edge Function** / 공개 웹: **GitHub Pages**

## 가장 중요한 구분

이 압축파일에는 **작동하는 브라우저 데모와 실제 서버에 연결할 수 있는 프로덕션 소스**가 모두 들어 있습니다. 하지만 **현재 Supabase 프로젝트 정보와 실제 담당자 사번이 제공되지 않았으므로 실서버는 배포/연결되지 않았습니다.**

- `DEMO_MODE: true`(기본): 같은 브라우저에서 화면·예약을 테스트할 수 있습니다. 데이터는 그 **브라우저의 localStorage에만 저장**되며 여러 기기에 공유되지 않습니다. 실운영으로 사용하지 마세요.
- `DEMO_MODE: false`: 운영 중인 Supabase Edge Function을 `API_URL`에 연결해야 합니다. 이때 PostgreSQL의 제약으로 **실제 동시 예약도 차단**합니다.

## 1. 바로 화면 실행하기 (데모)

압축을 해제하고 해당 폴더에서 터미널을 열어:

```bash
python -m http.server 5173
```

브라우저로 `http://localhost:5173`을 엽니다. 폴더에 `index.html`이 보이는 위치에서 명령을 실행해야 합니다.

> HTML 파일을 더블클릭해 `file://`로 직접 열면 JSON 로딩이 차단될 수 있습니다. 간단한 웹서버로 실행하세요.

데모 전용 담당자 체험 번호(실제 사번이 아닙니다):

- 통합 예약 그룹 **900001**
- 창업 예약 그룹 **900002**

해당 체험 번호는 데모 기능에만 존재하며, 실제 운영 서버에서는 사용되지 않습니다.

## 2. 운영 서버 설정하기

**초보자용 상세 절차는 [docs/운영설치_가이드.md](docs/운영설치_가이드.md) 파일을 먼저 읽으세요.**

1. Supabase 프로젝트 생성
2. `supabase/migrations`의 SQL 스키마와 88개 명단 등록
3. Edge Function `monitoring-api` 배포 (`verify_jwt=false`)
4. Supabase Secrets에 담당자 번호 2개 및 **32자 이상**의 세션 비밀키 등록
5. 실제 주말 예약 여부를 `true` 또는 `false`로 설정
6. `app.config.js`에서 `DEMO_MODE: false`, `API_URL` 설정
7. 브라우저에서 예약 생성·변경·취소·동시 중복 차단 테스트
8. GitHub Pages 등 정적 호스팅에 공개 웹파일 배포

실서버에 두 담당자 번호가 없으면 인증을 거부합니다. 서버의 서비스 롤 키를 공개 페이지에 적지 마세요.

## 4. 테스트

Node.js 20 이상이 있으면:

```bash
npm test
```

자동 테스트로 동아리 명단, 시간 선택 목록, 예약 그룹 독립성과 동일 그룹 중복 차단 등 프런트엔드 규칙을 검사합니다.

실제 Supabase의 원자적 동시 처리, 사번 권한, 브라우저 간 동기화 테스트는 **운영 프로젝트를 연결한 후 반드시 추가 수행**해야 합니다.

## 5. 변경 가능한 설정

`app.config.js`

```js
window.MONITORING_CONFIG = Object.freeze({
  DEMO_MODE: true,
  API_URL: '',
  WEEKENDS_ENABLED: null, // 운영자가 결정한 뒤 true 또는 false
  FIRST_DATE: '2026-10-26',
  LAST_DATE: '2026-11-27',
  TIMEZONE: 'Asia/Seoul'
});
```

운영에서는 위 공개 설정의 `WEEKENDS_ENABLED`와 **서버의 `WEEKENDS_ENABLED` 비밀 환경변수**를 동일하게 지정해야 합니다. 미확정(`null`) 상태에서는 주말 예약이 비활성화되며, 평일 예약은 가능합니다.

기본 **18:00은 종료 시각**이므로 18:00 자체는 예약할 수 없습니다. 변경을 원할 경우 프런트엔드/SQL/서버 검사와 테스트를 함께 수정해야 합니다.

## 6. 파일 및 데이터 유의사항

- 원본 엑셀의 학과, 학생 이름, 교수 이름 등 개인정보는 초기 데이터에 포함하지 않았습니다.
- 동아리 명단은 실제 두 개의 업로드 엑셀에서 88개를 추출했습니다. 사업별 전공동아리는 하나로 통합했습니다.
- 창업의 '레이븐즈 이스포츠'와 전공의 'RAVENS'는 별도 ID입니다.
- 사이트는 기존 오산대학교 일정 관리 사이트를 수정하지 않습니다. 연결은 나중에 링크를 추가하는 방식으로 진행합니다.
- 사번 하나만으로 인증하므로 사번 유출 시 권한을 도용할 수 있습니다. 한 번 쓰는 간소한 시스템이라는 운영상 위험을 인지해야 합니다.
- 실제 방문 소요시간이 확정되지 않아 **15분 간격은 시작 시각 간격**으로만 적용합니다.
