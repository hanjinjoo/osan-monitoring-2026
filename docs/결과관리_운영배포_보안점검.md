## 비공개 데이터 및 롤백

- 공개 GitHub에는 학과명만, 지도교수·대표학생 이름은 **별도 비공개 SQL**로 보관한다. 비공개 SQL을 GitHub PR이나 이슈에 복사하지 말 것.
- 결과관리 새 테이블은 기존 reservations 등을 변경하지 않는다.
- 프런트엔드 비활성화 시 기존 예약 기능은 유지하고, 새 보고서 데이터와 사진은 삭제하지 않는다.
- 운영 데이터가 들어간 뒤 SQL DROP으로 되돌리는 것을 금지한다. 복구 및 백업 정책부터 확보.
- 남은 필수 보완: 로그인 시도 제한, 업로드 미완료(pending) 정리, 권한·사진 보관 기한, 장시간 세션 만료 시 UX, storage CORS 및 전역 용량 검증.
